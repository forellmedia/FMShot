# 0005 – OCR über die Systemengines

**Status:** angenommen

## Entscheidung
Trait `OcrEngine` in `grabmark-ocr` mit drei Backends:
- macOS: Apple **Vision** (`VNRecognizeTextRequest`)
- Windows: **Windows.Media.Ocr**
- Linux: **Tesseract**, zur Laufzeit geladen; .deb empfiehlt
  `tesseract-ocr` + `tesseract-ocr-deu`.

Funktionen v0.1: Aufnahmemodus „Text erfassen“, „Text kopieren“ im Editor,
Volltextsuche in der Galerie (Hintergrund-OCR → FTS5), Auto-Schwärzen.

## Folgen
Ergebnisse unterscheiden sich je Plattform; dafür keine 20–40 MB Zusatzgewicht
und beste Qualität auf macOS.
